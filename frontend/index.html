Silicon Studio IDE V3.0 — Zero-Copy Neuro-Symbolic Architecture

        
      

      

        
Bi-Directional Project Sync: Switching projects in the top dropdown updates .silicon_studio/workspace.json so GitHub Copilot agents automatically target that project. Conversely, when an agent creates or switches projects in chat, the UI switches live via WebSocket.

        
1. Tab 1 (RTL & Architecture): Displays Verilator static lint sign-off, package-first compile order, and interactive Hierarchy + Word-Level RTL block schematics.

        
2. Tab 2 (DV & Waveforms): Displays deduplicated WaveDrom timing diagrams alongside the COI Dual-Edge (t vs t - 1ps) setup table and interactive COI Graph Visualizer.

        
3. Tab 3 (Synthesis, Gate Netlists & PPA): Displays Multi-PDK PPA metrics (sky130, nangate45, asap7), dynamic Hamming bit-flip power, and staged Gate-Level Netlist schematics.
